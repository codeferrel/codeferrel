<h3 align="center">🧊 3D Contribution Calendar</h3>

<p align="center">
Kalender commit dalam bentuk 3D, otomatis ter-update setiap hari lewat GitHub Actions.<br/>
<sub>⚠️ Gambar di bawah hanya akan tampil setelah workflow Actions dijalankan minimal sekali (lihat panduan setup).</sub>
</p>

<div align="center">
<img src="https://raw.githubusercontent.com/codeferrel/codeferrel/main/profile-3d-contrib/profile-night-rainbow.svg" width="95%" alt="3D Contribution Calendar"/>
</div>

<details>
<summary align="center">⚙️ <b>Cara setup widget 3D ini (klik untuk lihat)</b></summary>

<br/>

1. Buka repo profil kamu: `github.com/codeferrel/codeferrel`
2. Buat folder baru bernama `.github/workflows/`
3. Di dalamnya, buat file bernama `profile-3d-contrib.yml`
4. Isi file tersebut dengan kode yang ada di file `profile-3d-contrib.yml` (lihat terpisah di bawah)
5. **Commit** file tersebut langsung ke branch `main`
6. Buka tab **Actions** di repo kamu → pilih workflow **"GitHub 3D Contribution"** di sidebar kiri → klik tombol **Run workflow** (jalankan sekali secara manual)
7. Tunggu sampai status run berubah jadi ✅ hijau (biasanya 1-2 menit)
8. Refresh halaman profil kamu — folder baru `profile-3d-contrib/` akan otomatis muncul berisi beberapa file SVG, dan gambar di atas akan langsung tampil
9. Setelah ini, workflow akan jalan otomatis setiap hari (sesuai jadwal `cron`) tanpa perlu kamu jalankan manual lagi

> 💡 Kalau mau ganti warna tema, file SVG lain yang tersedia di folder itu antara lain: `profile-night-green.svg`, `profile-night-blue.svg`, `profile-south-american-warm-winter.svg`. Tinggal ganti nama file di URL `<img>` di atas.

</details>
